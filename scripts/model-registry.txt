# Accepted values for the `model:` field in an agent role file.
#
# One value per line. Blank lines and lines starting with # are ignored.
# Matching is exact and case-sensitive. A value is accepted only when it is
# listed here. The shape of a value is never checked, because no two harnesses
# spell a model the same way, and a pattern would refuse a spelling somebody's
# harness accepts. A harness is the program that runs the agent loop and reads
# these files.
#
# The file ships with no values in it. No role file here names a model, because
# a model identifier is a fact about one harness and one vendor, and the roles
# are neutral. Fill this in with the identifiers your own harness accepts,
# taken from that harness's own documentation, the first time a role pins one.
# Where an adapter maps each role to a model, that mapping is the better home
# for an identifier, and this file stays empty.
#
# check-roles.py reads this file. A role naming a value that is not here is
# not reported as an error. It is reported as a question, because the checker
# cannot tell a typo from a model nobody has registered yet, and guessing in
# either direction is worse than asking. Resolve it one of two ways:
#
#   The value is a typo        -> fix the role file.
#   The value is a real model  -> add one line here, with a comment saying
#                                 what it is and where you confirmed it.
#
# Every entry carries that comment. A bare identifier with no provenance is how
# a registry rots: a year later nobody can say whether the value still works,
# or who said it did. The form is one line:
#
#   <value>   # what it is, where it was confirmed, the date it was read
#
# Two shapes are worth knowing before you add one. A short alias, which the
# harness resolves to whatever model it has configured, and a full identifier
# that names one model exactly. Register either. Register both spellings when a
# harness accepts a dated and an undated form of the same model, so that no
# commit is blocked over which one is canonical.
#
