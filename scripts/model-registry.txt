# Accepted values for the `model:` field in an agent role file.
#
# One value per line. Blank lines and lines starting with # are ignored.
# Matching is exact and case-sensitive.
#
# check-roles.py reads this file. A role naming a value that is not here is
# not reported as an error. It is reported as a question, because the checker
# cannot tell a typo from a model nobody has registered yet, and guessing in
# either direction is worse than asking. Resolve it one of two ways:
#
#   The value is a typo        -> fix the role file.
#   The value is a real model  -> add one line here, with a comment saying
#                                 what it is and where you confirmed it.
#
# The aliases below are from the Claude Code subagent documentation,
# https://code.claude.com/docs/en/sub-agents, read 2026-09-11. That page says a
# full model ID is also accepted, and does not enumerate them or state a
# grammar for one. That is why this file is a list and not a pattern: nothing
# about the shape of a value separates a new model from a typo.
#
# Each full ID below therefore carries its own provenance, per the rule above.

# Aliases
sonnet
opus
haiku
fable

# Take the model of the session that dispatched the role.
inherit

# Full Anthropic model IDs. The four below are the ones a Claude Code session
# reported as current in its own environment on 2026-09-11. That is a weaker
# source than the documentation and is stated as such: it is what one session
# said on one day, not a published list.
claude-opus-5
claude-sonnet-5
claude-fable-5-1
claude-haiku-4-5-20251001
# Both spellings of Haiku 4.5 are registered. A session reported the
# date-suffixed form; the model reference lists the undated one. Registering
# both costs a line and avoids blocking a commit over which is canonical.
claude-haiku-4-5

# A self-hosted or non-Anthropic model does not belong in this file, because it
# does not belong in a role's `model:` field. Checked 2026-09-11 against
# https://code.claude.com/docs/en/llm-gateway, which states that Anthropic does
# not support routing Claude Code to non-Claude models through any gateway.
# Running against other infrastructure is configured in the environment
# instead: ANTHROPIC_BASE_URL, the ANTHROPIC_DEFAULT_*_MODEL variables, and the
# Bedrock and Vertex switches. A role still names an alias such as `opus`, and
# the environment decides where that resolves. Nothing in this file changes
# that, either way.
