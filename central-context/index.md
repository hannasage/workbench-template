# index.md

The catalog. One line per wiki page, grouped by domain. Read this first on
every query.

Each line is a wikilink and a summary of ten words or fewer. A line that needs
a sentence belongs on the page, not here. The shape is in `AGENTS.md`, under
"The two flat files".

Empty. The first `wiki-ingest` run writes the first domain heading and the
first line under it.
